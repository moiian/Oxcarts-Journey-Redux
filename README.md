# Oxcarts Journey Redux 4.17

将 OJR 的乘客旅行模式与 Let me drive oxcart 的原生司机位、手动驾驶整合为一个 REFramework 模组。随从控制及座位预设只有一份，不再同时运行两个独立模组。

## 安装与入口

复制整个 `reframework/autorun` 内容到游戏同名目录：

```text
autorun/
  Oxcarts Journey Redux.lua          # 唯一启动入口
  Oxcarts Journey Redux/
    journey.lua                     # 乘客旅行、共用随从控制及预设菜单
    driver.lua                      # 原生司机交互、手动转向及玩家显示位置
    presets.lua                     # 单一预设库、旧配置迁移
    speed.lua                       # 四档速度、当前牛的限时普通移动命令
    hud.lua                         # 乘客技能栏文字及退出恢复，保留原生配色
    protection.lua                  # 当前牛/车体身份和已知附近部件的免伤判断
    display.lua                     # 同行者显示位置及模拟前恢复
    pelvis.lua                      # 按角色启用的 Lock Height
    diagnostics.lua                 # 按需开启的运行证据，正常游玩关闭
```

不要同时启用旧的 `Let me drive oxcart.lua` 或另一份 OJR 启动脚本。升级时停用旧 LMD 启动脚本，避免重复加载；本模组不依赖旧脚本、debug 工具或其他 MOD。安装后执行 REFramework **Reset scripts** 或重启游戏。

## 两种模式

乘客模式沿用原生乘客位和 OJR 的车票、路线逻辑。自动冲刺及终点减速仅在此模式运行。手动调档后暂停自动加速，可点击 `Resume passenger auto cruise` 恢复；手动 Dash 成功后 5 秒正常游戏时间自动交回巡航，后续速度输入重置或取消这个倒计时。

司机模式通过原生司机交互进入。热键仅在 `Signed forward from driver point` 为 **0–3** 时响应；长按超过 **0.3 秒**请求牛车 Wait，满 **1 秒**请求上车。菜单按钮仍是直接请求入口。上车后牛车等待 **8 秒**，玩家显示位置、FOV、镜头距离也延迟 **8 秒**生效。每次进入使用当前车型第一个启用预设。司机模式不会自动加速或终点减速。

已有 NPC 司机先解除原生司机交互，确认解绑后真实传送到车后 **500**；附近未上车的已识别司机也会被一次性移走。没有司机则跳过；司机退出未完成或请求失败时停止本次玩家上车，不强抢绑定。不恢复 NPC 司机，不通过冻结 NPC FSM 留住它。

## 默认按键

| 操作 | 键盘 | 手柄 |
|---|---|---|
| Let me drive（长按 1 秒） | F | B / Circle |
| Let pawns sit / 下一预设 | E | X / Square |
| Let pawns stand（仅释放同行者） | F | B / Circle |
| Let me stand（停止脚本控制及玩家预设） | X | A / Cross |
| 转向（仅司机模式） | A / D | 左摇杆 |
| 加速一级 | W | RB / R1 |
| 减速一级 | S | LB / L1 |

进入司机位与随从起身共用默认按键，由当前座位状态区分。`Let me stand` 不额外强制原生下车；A / Cross 的原生下车由游戏处理。乘客和司机模式使用同一组主要映射；旧 OJR 修饰键保留为乘客模式备用控制。

## 共用预设与同行者

每个车型预设包含独立的乘客位玩家参数、司机位玩家参数，以及共用的最多 **9 名同行者**参数。主 Pawn 优先，其他 PawnManager 队员随后，正在跟随玩家的 NPC 最后；已有成员保留槽位，新成员补空位。未做四随从 MOD 专用适配，但队伍成员顺序读取方式保留。

预设以原 OJR 乘客布局为基础，共用随从位置并分别保存两种玩家位置。升级会移除旧 `(driver import)` 布局及带司机导入标识的布局，保留其他已调好的参数和用户新增布局。名称统一为 `[序号] 名字`，例如 `[1] Facing Each Other`。只保存 `OxcartsJourneyRedux.json`，不再写入原 `LetMeDriveOxcart.json`。

`Restore all built-in layouts` 恢复七个原乘客内置布局，包括各自的乘客玩家参数、司机玩家参数、司机镜头参数及共用随从参数，也会补回被删除的内置布局；用户新增布局不改。预设菜单按车型、布局下拉显示，同行者编辑槽按人数动态显示。`Adjust Player` 同时控制两种玩家位置修正；`Skip this preset when player is passenger` 只让乘客轮询跳过该布局，不影响司机轮询或手动编辑。

菜单 `Active layout` 的选择排到行为更新阶段处理，与热键走完整坐姿切换流程，不在菜单绘制时直接改变动画或 FSM。`Backup keybinds` 位于 `Keybind settings` 内，保留旧修饰键操作。

同行者的真实锚点使用当前车型第一个预设，位置与 `PosRotContext`、物理控制器同步；当前预设决定显示位置，下一次模拟前恢复真实位置。不请求原生座椅交互，不传送到车头。首次坐下、切换预设、随机坐姿及直接 Bank/Motion 均在请求帧定位、重置跌落和请求坐姿，下一次行为更新冻结 FSM；日常跟随及拍照不重复重置跌落。解绑将当前显示位置交接给真实位置，恢复接管前 FSM，不传回上车起点。单人失败不阻断整组清理；FSM 恢复失败保留原状态，每秒重试、每轮最多 5 次，超限记录保留至脚本重载重新尝试。
照片模式继续显示玩家及同行者的位置；司机模式的 FOV 和镜头距离不应用到照片模式。玩家不参与同行者 FSM 冻结或物理传送。

完整互动与解除条件见 [流程审查](docs/unified-flow.md)。

## 牛车控制、技能栏与保护

两种模式共用 `Wait → Walk → Run → Dash` 四档，不冻结牛的 FSM。有效 Run/Dash 命令期间阻止基础层 TurnTarget 和普通减速动作接管；已经进入 TurnTarget 时恢复目标速度。其他特殊动作、受击、死亡、暂停、无司机、到站及命令到期仍按相应边界让出控制。Run 和 Dash 使用同样的速度保持时长。

NPC 司机必须实际占用司机位且 `isSit()` 为 true，才允许乘客行车或调速；在车旁不算在座。玩家手动驾驶可行车。乘客 Run/Dash 时站起保留同行者，重新坐下或整组解除会清掉这项保留；玩家距车体中心大于 15 时释放同行者。已付费行程距牛大于 15 的停车判断独立存在。

只有乘客模式修改技能栏文字，保留原生配色和按下效果；文字/显示状态未变化时不重复设置。离座或接管司机模式时恢复仍由本模组写入的内容。司机模式仅隐藏技能栏绘制，结束驾驶后恢复。

牛车保护不使用伤害倍率。当前牛、实际连接的牛、车体及 PartsList 部件按对象身份匹配；已知同型号部件在车体周围 12 范围内补充识别，这可能覆盖极近的另一辆牛车同型号部件，属于保留的识别策略。玩家距当前牛不超过 20 时维护相关目标的 `HitController.IsInvincible`，目标更换、离开范围或脚本重置时恢复原值。司机、守卫不因此获得免伤。防散架另外保护实际车体及关联部件，玩家距车体小于 50 才生效。

对 `GenerateManager.requestDestroy` 的定向保护仅在玩家实际占用当前牛车乘客位或司机位时生效，保护牛、子容器及实际在座 NPC 司机；站起、加载、快速旅行或状态读取失败时放行，不保护被驱逐司机。

正常游玩关闭详细证据收集和成功状态日志，保留错误提示。只有明确设置 `OJR_EnableRuntimeDiagnostics=true` 才收集/保存运行证据。按角色的 `Lock Height` 默认关闭；开启后在新坐姿冻结完成的下一帧采集骨盆基准，不改变真实锚点。

## 验证与版本

在项目根目录运行：

```powershell
./tests/run-unified-tests.ps1
```

需要 Python 及与 Python 架构一致的 Lua 5.3 动态库；使用 `OXCART_TEST_LUA_DLL` 指定 DLL 路径。它们只用于测试，游戏运行不需要这些测试依赖。套件覆盖入口加载、座位/物理/显示分离、预设、相机/照片模式、司机进入和退出、速度/TurnTarget、无司机停车、伤害/销毁保护、失败恢复及旧测试入口移除。独立 tool2 仅在本地同时存在其脚本时追加隔离 mock 测试，不是正式回归的必需依赖。

4.17 完整模拟回归通过；用户已实测乘客和玩家驾驶、Dash 转弯、主动停车、下车及同行者恢复，无明显问题。实测范围不代表所有地图、任务或模组组合都已验证。安装包仅含 10 个 Lua、modinfo.ini 和 screenshot.jpg，不含 tests、debug、用户配置或备份。

本分支为 `experimental/unified-oxcart`，与 `main` 分开维护。4.16 修复动作 hook 异常放行、FSM 恢复保留及整组释放隔离，并改善 Dash 转弯保持；4.17 清理旧司机实验、内嵌录制器、专用观察 hook 和死代码，正式功能保留。
